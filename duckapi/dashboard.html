Client IP policy and request limit

Enter one IP address or CIDR range per line. If the allowlist is not empty, only matching addresses can use model endpoints; the blocklist always takes precedence. Rate limits are per IP, per rolling 60 seconds. Set the limit to 0 to disable it.

Settings persist in the local runtime-policy.json file. Rate-limit counters are in memory and reset when the server restarts.
